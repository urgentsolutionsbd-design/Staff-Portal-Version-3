# Staff Performance Portal V3

Frontend starter for Staff Performance Portal Version 3.

## Included

- `index.html` — Staff/Admin starter login
- `staff.html` — Staff dashboard starter
- `admin.html` — Admin dashboard starter
- `css/style.css` — Shared responsive design
- `js/app.js` — Login/demo session behavior
- `js/staff.js` — Staff dashboard navigation/demo attendance
- `js/admin.js` — Admin dashboard navigation

## Important

This is a **frontend starter only**. Authentication, Google Sheets, API endpoints, secrets, real attendance, KPI data and admin actions are **not connected yet**.

Do not place passwords, Google service-account keys, API secrets or private sheet credentials directly in these frontend files.
